Módulo 1 · Fundamentos

O que é Informática

A palavra nasce da fusão de informação + automática. É a ciência que estuda o tratamento automático e racional da informação.

Repare na definição: o objeto de estudo não é o computador — é a informação. O computador é apenas a máquina que escolhemos para tratar essa informação de forma automática. Antes dele, o tratamento era manual: um escriturário somando colunas num livro-caixa também fazia processamento de dados, só que lentamente e com erros.

As quatro funções da Informática

  • Desenvolvimento de novas máquinas — projetar hardware capaz de tratar mais dados, mais rápido e com menos energia.
  • Desenvolvimento de novos métodos de trabalho — descobrir formas melhores de organizar e resolver problemas com o computador.
  • Construção de aplicações automáticas — transformar esses métodos em programas que funcionam sozinhos.
  • Melhoria de métodos e aplicações existentes — otimizar o que já existe, tornando mais rápido, seguro ou barato.

Dado ≠ Informação

Essa distinção é a base de tudo. Dado é o fato bruto, sem contexto: 7,4. Informação é o dado processado e contextualizado: a média final do aluno em Informática foi 7,4 — aprovado. O computador recebe dados, processa e devolve informação.

Módulo 1 · Fundamentos

Bit, byte e o sistema binário

O computador só sabe distinguir dois estados: tem corrente ou não tem. Chamamos esses estados de 1 e 0 — e absolutamente tudo é construído a partir disso.

Dentro do processador existem bilhões de chavinhas microscópicas (transistores). Cada uma está ligada ou desligada. Não existe “meio ligada”. Essa limitação, longe de ser um defeito, é o que torna o computador confiável: é muito fácil distinguir 0 volt de 3 volts, mesmo com ruído elétrico.

  • Bit (binary digit) — a menor unidade de dado. Vale 0 ou 1. Sozinho, representa apenas duas possibilidades.
  • Byte — um conjunto de 8 bits. Com 8 chavinhas conseguimos 28 = 256 combinações diferentes: o suficiente para representar uma letra, um número ou um símbolo.

Por que 8 bits viraram um byte?

Porque 256 combinações cobrem confortavelmente o alfabeto maiúsculo e minúsculo, os algarismos, a pontuação e os caracteres de controle. Essa tabela de correspondência entre número e caractere chama-se ASCII — e é por ela que o número 65 vira a letra A.

Como se lê um número binário

Cada posição vale o dobro da anterior, da direita para a esquerda: 1, 2, 4, 8, 16, 32, 64, 128. Para converter, some os valores das posições que estão em 1. Assim, 01101001 = 64 + 32 + 8 + 1 = 105.

Módulo 1 · Fundamentos

Hardware, Software
e Peopleware

Todo sistema de computação tem três partes. Duas você compra; a terceira você forma.

  • Hardware — a parte física do sistema de computação. Tudo que você pode tocar: o sistema central (gabinete, placa-mãe, processador, memória) e os periféricos.
  • Software — a parte lógica. Os programas e dados: software básico, utilitários e aplicativos. Não tem peso nem volume, só existe enquanto instruções.
  • Peopleware — as pessoas que trabalham com o computador: digitadores, programadores, analistas, técnicos e usuários. É a parte que toma decisões.

Existe uma piada clássica que resume bem: software é a parte que você xinga; hardware é a parte que você chuta. Ela funciona porque toca numa verdade — quando algo não funciona, é preciso saber em qual das três camadas está o problema. Trocar de computador porque o Word travou é resolver na camada errada.

Módulo 2 · Hardware

O caminho do dado
dentro da máquina

Todo computador, do celular ao supercomputador, executa o mesmo ciclo: entrada → processamento → saída, com o armazenamento guardando o que precisa sobreviver ao desligamento.

Os componentes principais de qualquer sistema de computação são três: processador, memória principal e dispositivos de entrada e saída. O que muda de um equipamento para outro é o tamanho, a velocidade e o formato — nunca a lógica.

Sistema Central e Periféricos

O Sistema Central é o núcleo: processador + memória principal, ligados pela placa-mãe. Os periféricos são tudo que se conecta ao redor para trazer dados de fora ou levar resultados para fora — teclado, mouse, monitor, impressora, pen drive.

Módulo 2 · Hardware

O processador:
UC e ULA

A CPU não é uma caixa mágica. Ela repete, bilhões de vezes por segundo, um ciclo de três etapas — e reparte o trabalho entre duas unidades com funções bem definidas.

  • Unidade de Controle (UC) — responsável pelo fluxo de dados e pela interpretação de cada instrução do programa. Todo o processamento é controlado e coordenado por ela. É o “maestro”.
  • Unidade Lógica e Aritmética (ULA) — responsável pelas operações aritméticas (somar, subtrair, multiplicar) e lógicas (maior que, igual a, E, OU), incluindo a tomada de decisão. É coordenada pela UC.
  • Registradores — pequenas gavetas de memória ultrarrápidas dentro do próprio processador, onde ficam os valores sendo usados agora.

O ciclo de instrução

Toda instrução passa por três fases: buscar (a UC vai à memória pegar a próxima instrução), decodificar (a UC descobre o que ela significa) e executar (a ULA faz a conta, ou o dado é movido). Depois, o ciclo recomeça. Um processador de 3 GHz repete esse ciclo cerca de 3 bilhões de vezes por segundo.

    Módulo 2 · Hardware

    RAM e ROM:
    a questão da volatilidade

    Duas memórias, dois comportamentos opostos quando falta energia. Entender essa diferença explica metade dos problemas do dia a dia.

    RAM — Random Access Memory

    • É a memória de trabalho: onde o programa e os dados ficam enquanto estão em uso.
    • Permite gravação e leitura — o processador escreve e lê livremente.
    • É volátil: o conteúdo é perdido assim que a energia é cortada.

    ROM — Read Only Memory

    • Usada para fins específicos, gravada pelo fabricante.
    • É de somente leitura pela CPU em operação normal.
    • É não volátil: continua memorizando mesmo sem energia. Nunca perde o conteúdo.

    É a ROM que guarda o BIOS/UEFI — o primeiro programa que roda quando você aperta o botão liga. Sem ela, o computador não saberia sequer como procurar o sistema operacional no disco.

    Módulo 2 · Hardware

    Hierarquia
    de memória

    Existe uma troca inevitável: quanto mais rápida a memória, mais cara e menor ela é. Por isso o computador usa várias camadas em vez de uma só.

    A memória se divide em principal (RAM e cache, ligadas diretamente ao processador) e secundária ou auxiliar — os meios de armazenamento: pen drives, cartões SD, discos rígidos, SSDs, DVD/CD/BluRay e, historicamente, disquetes e unidades de fita.

    Se a memória mais rápida fosse barata, o computador teria só ela. Como não é, o sistema mantém o dado mais usado o mais perto possível da CPU e empurra o resto para baixo na pirâmide.

    Módulo 2 · Hardware

    Tipos de
    computadores

    Recomendar a máquina certa não é escolher a mais cara. É casar o perfil de uso com a configuração — e saber justificar tecnicamente.

    • Desktop — fixo, melhor custo-benefício por desempenho, fácil de atualizar e refrigerar. Perde em mobilidade.
    • Notebook / Laptop — portátil e autônomo (bateria). Custa mais pelo mesmo desempenho e é mais difícil de atualizar.
    • Tablet — consumo de conteúdo, leitura e anotações. Interface por toque, ótima autonomia, produtividade limitada.
    • Servidor — projetado para ficar ligado 24 horas, com armazenamento redundante, ECC na memória e acesso centralizado por rede.
    • Mainframe / Supercomputador — volume massivo de transações ou cálculo científico. Fora da realidade doméstica.

    O teclado
    por dentro

    Módulo 4 · Software

    O Sistema Operacional
    e suas quatro gerências

    O SO é o gerente principal do hardware. Para que o computador funcione de forma eficiente, ele realiza quatro gerências essenciais — simultaneamente, o tempo todo.

    • Gerência de memória — controla quais partes da memória estão em uso e por quem, garantindo que um programa não interfira no espaço de outro.
    • Gerência de processador — escalona qual tarefa deve ser executada pela CPU em cada momento, otimizando o tempo de resposta.
    • Gerência de arquivos — organiza como os dados são armazenados, nomeados e acessados em discos ou SSDs.
    • Gerência de dispositivos de E/S — coordena a comunicação com periféricos: teclados, mouses, impressoras, monitores.

    Além disso, o SO tem três objetivos de projeto: prover interfaces mais simples que as de baixo nível, tornar os aplicativos independentes do hardware e definir interfaces homogêneas para dispositivos de tecnologias distintas. É por isso que o mesmo Word imprime numa impressora nova ou numa de dez anos atrás sem saber a diferença.

    Licenças
    de software

    O que você compra ao “comprar” um programa não é o programa — é o direito de usá-lo sob certas condições. Entender isso evita problemas legais reais.

    • Software proprietário — conceito criado por empresas para proteger o produto de qualquer tipo de alteração. A licença proíbe distribuição ou cópia sem autorização do proprietário. Exemplos: Windows, Corel, Photoshop, Microsoft Office.

    Suspender, hibernar
    ou desligar?

    Quatro estados de energia com efeitos bem diferentes sobre a memória, o disco e o consumo. Escolher errado custa tempo — ou custa o trabalho não salvo.

    • Suspensão — coloca o trabalho e as configurações na memória RAM e usa uma pequena quantidade de energia. Retomada quase instantânea. Se a bateria acabar, perde-se tudo.
    • Hibernação — coloca os documentos e programas abertos no disco rígido e desliga o computador. Consumo zero, retomada mais lenta, e nada se perde.
    • Suspensão híbrida — projetada para desktops. Combina as duas: grava na memória e no disco, e coloca o computador em estado de baixa energia. Retoma rápido e resiste à queda de energia.
    • Desligar — encerra tudo completamente. É o necessário para instalar atualizações, trocar peças ou resolver travamentos.
    • Logoff / Trocar usuário — encerra a sessão sem desligar. Útil quando outra pessoa precisa acessar o mesmo computador com a conta dela.

      Módulo 6 · Internet

      Página, URL
      e protocolo HTTP

      Aquele endereço na barra do navegador não é um texto qualquer. Cada pedaço dele tem uma função, e ler um endereço corretamente é a primeira defesa contra golpes.

      Página web

      Uma página web (webpage) é uma “página” na world wide web, geralmente em formato HTML, com ligações de hipertexto que permitem a navegação de uma página, ou seção, para outra.

      URL

      URL é a sigla de Uniform Resource Locator — Localizador Padrão de Recursos. Ela se refere ao endereço de rede onde se encontra algum recurso informático: um arquivo, um dispositivo periférico (impressora, multifuncional, unidade de rede). Essa rede pode ser a Internet ou uma rede corporativa, como uma intranet. Exemplo: portal.ifs.edu.br.

      HTTP

      O HyperText Transfer Protocol é o protocolo de aplicação responsável pelo tratamento de pedidos e respostas entre cliente e servidor na World Wide Web. As transações seguem regras básicas fixas. O HTTPS é a mesma coisa, com criptografia — e é por isso que ele exibe o cadeado.

      Correio eletrônico

      O e-mail é uma ferramenta para enviar e receber mensagens de maneira quase instantânea pela Internet. É gratuito e aceita fotos e arquivos de todo tipo em anexo.

      Anatomia de um endereço

      Todo endereço tem a forma nome@domínio. O que vem antes do @ identifica a caixa postal; o que vem depois identifica o servidor que a hospeda. Em eber.santana@ifs.edu.br, a caixa é eber.santana e o servidor é o do IFS.

      Campos de destinatário

      • Para — o destinatário principal, de quem se espera uma ação ou resposta.
      • Cc (com cópia) — quem precisa ficar sabendo. Todos veem quem recebeu.
      • Cco (com cópia oculta) — os demais destinatários não veem esse endereço. É o campo correto para enviar a uma lista grande sem expor os e-mails de todo mundo.

          Módulo 7 · Suítes de escritório

          Planilha eletrônica
          e a função SE

          A planilha não guarda números — ela guarda relações entre números. Mude uma nota e tudo que depende dela se recalcula sozinho.

          Toda fórmula começa com =. A partir daí você combina referências de células (A2), operadores (+ − * /) e funções (SOMA, MÉDIA, SE).

          A função SE

          O SE é uma função comparativa: compara valores e retorna resultados diferentes conforme o que foi descrito na fórmula. A estrutura é:

          =SE(teste_lógico; valor_se_verdadeiro; valor_se_falso)

          • Teste lógico — a condição que será testada. Ex.: A4>=7
          • Valor se verdadeiro — o que aparece se a condição for atendida.
          • Valor se falso — o que aparece caso contrário.

          Aplicada ao caso do aluno: =SE(A4>=7;"Aprovado";"Reprovado"). Lembre-se sempre de colocar textos entre aspas — sem elas, a função não funciona.
